# 정인애 퍼스널 트레이너 랜딩 페이지 설계

## 목표

1986피트니스 지축점을 찾는 잠재 회원이 정인애 PT팀장의 지도 철학과 차별점을 이해하고, 사진·영상·상담 채널이 준비되기 전에도 신뢰할 수 있는 소개 페이지를 경험하게 한다. 현재 CTA는 외부 전송이 없는 `상담 준비 중` 상태로 제공한다.

## 범위

- GitHub Pages에 배포할 수 있는 단일 페이지 정적 웹사이트를 새로 만든다.
- 사용자가 제공한 소개문, 운동 철학 3가지, 차별점 4가지를 원문 의미를 유지해 편집한다.
- 실제 사진과 영상 대신 의도적으로 설계된 미디어 대기 프레임을 사용한다.
- 향후 영상과 회원 변화 사례를 기존 레이아웃을 깨지 않고 추가할 수 있는 확장 지점을 마련한다.
- 결제, 가격표, 회원 후기, 수치 성과, 상담 전송 기능은 만들지 않는다.

## 방문자와 핵심 행동

- 방문자: 통증 완화, 체형 개선, 다이어트, 근력 향상 또는 운동 입문을 위해 트레이너를 비교하는 사람
- 방문자가 이해해야 할 약속: 정인애 팀장은 평가를 기반으로 안전한 변화를 설계하고, 회원이 혼자서도 운동할 수 있는 상태를 목표로 지도한다.
- 현재 행동: 페이지를 읽고 `상담 준비 중` 상태를 확인한다.
- 향후 행동: 카카오톡, 전화 또는 인스타그램 상담 링크 중 선택된 채널로 이동한다.

## 레퍼런스 해석

### 확인한 소스

- URL: https://1986fitnessk.github.io/park-minseok-renewal/han-seulgi-renewal/
- 확인일: 2026-08-26
- 확인 화면: 1440px 데스크톱과 390px 모바일

### 가져올 원칙

- 큰 한국어 헤드라인과 절제된 설명이 번갈아 이어지는 에디토리얼 리듬
- 어두운 면과 밝은 면을 교차해 긴 페이지에서 주제를 전환하는 방식
- 히어로의 비대칭 2열 구성과 모바일의 의도적인 순서 재배치
- 섹션 번호와 짧은 영문 라벨로 긴 글을 탐색 가능하게 만드는 방식
- 실제 변화 기록을 같은 촬영 각도, 동일한 비율, 좌우 비교, 익명 처리, 짧은 캡션으로 제시하는 증거 구조
- 첫 화면의 순차 등장, 스크롤 진입 시 기록 요소의 상승, 선택·호버 시 짧은 반응처럼 목적이 분명한 모션

### 복제하지 않을 요소

- 한슬기 트레이너의 이름, 문구, 가격, 회원 사진, 로고 표현, 고유한 전체 배치
- 레퍼런스의 네이비·아이보리 색을 그대로 복제한 팔레트
- 제공 또는 검증되지 않은 회원 후기, 변화 수치, 자격, 연락처, 프로그램 가격

## 디자인 방향

정인애 팀장의 세심함과 운동 지도자로서의 단단함을 함께 보여주는 에디토리얼 코칭 페이지로 만든다. 잉크 블랙, 웜 아이보리, 절제된 버밀리언을 사용하고, 얇은 평가선과 큰 활자를 반복되는 시각 문법으로 삼는다. 같은 크기의 카드 모음 대신 비대칭 열, 번호가 있는 세로 흐름, 큰 선언문을 사용한다.

## 페이지 구조

### 1. 헤더

- `1986 FITNESS · JICHUK`과 `JEONG IN AE · PT TEAM LEADER`를 표시한다.
- 별도 메뉴 없이 현재 페이지의 정체성을 빠르게 확인하게 한다.

### 2. 히어로

- 긴장: `운동을 맡긴다는 건, 내 몸의 기준을 함께 세우는 일입니다.`
- 핵심 약속: `내 몸을 믿고 맡길 수 있는 지도자, PT팀장 정인애입니다.`
- 소속: `1986피트니스 지축점`
- 오른쪽에는 사진을 가장하지 않는 `코칭 기준 프레임`을 배치한다.
- CTA는 비활성 `상담 준비 중` 버튼과 준비 상태 설명으로 구성한다.

### 3. 소개와 문제 인식

- 통증, 바디라인, 체력 등 서로 다른 시작 이유를 인정한다.
- `정말 나를 잘 이끌어줄 수 있는 사람일까?`라는 방문자의 질문을 크게 보여준다.
- 숫자만 세는 수업이나 반복 루틴과 다른 평가 기반 지도를 설명한다.

### 4. 운동 철학

- `정확한 평가가 올바른 결과를 만듭니다.`
- `혼자서도 운동할 수 있는 자립을 목표로 합니다.`
- `과정은 즐겁게, 결과는 확실하게.`
- 세 항목을 `평가 → 이해 → 지속`의 세로형 코칭 흐름으로 연결한다.

### 5. 선언문 전환

- `운동은 견디는 고통이 아닌, 삶을 바꾸는 가장 확실한 투자입니다.`를 전체 폭 밝은 면에 배치한다.
- 다음 차별점 섹션으로 넘어가는 시각적 전환 역할을 한다.

### 6. 정인애 팀장의 네 가지 약속

- 체계적인 모니터링과 피드백
- 지도 경험 기반의 부상 예방 트레이닝
- 눈높이에 맞춘 세심하고 다정한 설명
- 지속 가능한 건강한 라이프스타일 디자인
- 같은 크기의 4개 카드 대신 첫 항목과 마지막 항목의 비중을 키운 비대칭 편집 레이아웃을 사용한다.

### 7. 향후 변화 기록 확장 지점

- 현재는 사례가 없는 빈 갤러리를 노출하지 않는다.
- 사진 제공 시 별도 기록 섹션을 네 가지 약속 뒤에 삽입한다.
- 같은 각도와 크롭, 좌우 비교, 촬영 조건 안내, 얼굴 비식별 처리, 실제 확인 가능한 설명만 사용한다.
- 정렬선은 실제 평가에 쓰인 경우에만 표시하며 장식용으로 결과를 과장하지 않는다.

### 8. 마지막 상담 영역

- `내 몸을 이해하는 것부터 시작합니다.`를 마지막 행동 문장으로 사용한다.
- 비활성 `상담 준비 중` 버튼과 `상담 채널을 준비하고 있습니다.`라는 설명을 함께 제공한다.

## 시그니처 구성과 컴포넌트

- 시그니처 구성: 큰 선언문과 평가선을 중심으로 텍스트와 코칭 단계가 교차하는 비대칭 에디토리얼 흐름
- 시그니처 컴포넌트: 히어로의 `코칭 기준 프레임`
- 프레임 단계: `01 평가`, `02 설계`, `03 수행`, `04 자립`
- 데스크톱에서는 세로 신체 정렬선처럼 보이고, 모바일에서는 가로 진행 표시로 변환한다.
- 실제 사진이 제공되면 프레임 내부 미디어만 교체하고 단계·캡션·대체 텍스트 구조는 유지한다.

## 타이포그래피와 색상

- 한국어 본문은 읽기 쉬운 Pretendard 계열의 라이선스가 확인된 로컬 웹폰트를 사용한다.
- 영문 라벨과 숫자는 폭이 좁고 단단한 산세리프 계열로 대비한다.
- 한국어 본문 자간은 0에 가깝게 유지하고, 큰 제목의 자간은 실제 모바일 줄바꿈을 확인한 뒤 최소한으로 조정한다.
- 색상 역할:
  - 잉크 블랙: 기본 배경과 신뢰감
  - 웜 아이보리: 본문과 밝은 전환 면
  - 버밀리언: 평가선, 현재 단계, 포커스와 짧은 강조
  - 중성 회색: 보조 설명과 비활성 상태
- 모서리는 최대 8px로 제한하고, 그림자보다 선과 면의 대비를 우선한다.

## 모션 설계

### 첫 화면: `assemble coaching standard`

- 페이지 진입 시 헤드라인, 수직 평가선, 네 단계 라벨이 차례로 조립된다.
- 총 길이는 약 900ms이며, 텍스트를 읽기 전에 과도하게 기다리지 않게 한다.

### 스크롤: `follow the coaching line`

- 철학 세 단계가 하나의 기준선을 따라 순서대로 나타난다.
- 각 항목은 40ms 간격으로 불투명도와 짧은 수직 이동을 조정한다.

### 마이크로인터랙션

- 읽을 수 있는 링크와 버튼의 호버·키보드 포커스 상태
- 코칭 기준 프레임 단계의 포인터 반응
- 차별점 항목 진입 시 번호와 선의 짧은 확장
- 비활성 CTA는 눌리지 않으며 커서, 색, 설명으로 상태를 명확히 한다.

### 모션 축소

- `prefers-reduced-motion: reduce`에서는 모든 요소가 즉시 최종 상태로 나타난다.
- 자동 이동, 반복 이동, 스크롤 위치와 연결된 장식 애니메이션을 사용하지 않는다.

## 반응형 설계

- 데스크톱: 2열 히어로, 비대칭 철학·약속 구성
- 모바일: 메시지 → 소속 → 코칭 프레임 → CTA 순으로 재배치
- 코칭 기준 프레임은 세로형에서 가로 진행형으로 변환한다.
- 네 가지 약속은 모니터링, 쉬운 설명, 부상 예방, 지속 가능한 습관 순으로 읽히게 재배치한다.
- 320px, 360px, 390px, 430px에서 가로 스크롤, 버튼 줄바꿈, 한국어 고아 음절, 헤드라인 겹침을 확인한다.

## 기술 구조

- 별도 프레임워크 없는 정적 HTML, CSS, JavaScript를 사용한다.
- GitHub Pages의 하위 경로에서도 동작하도록 상대 경로만 사용한다.
- 핵심 본문은 HTML에 유지하고, 상담 링크와 미디어 경로 같은 교체 값만 JavaScript 설정 객체에 모은다.
- CSS 사용자 지정 속성으로 색, 간격, 타이포그래피, 모션 시간을 정의한다.
- 자바스크립트가 비활성화되어도 모든 본문과 비활성 CTA가 읽히는 점진적 향상을 적용한다.

## 상태와 오류 처리

- 현재 CTA는 네이티브 `button disabled`와 상태 설명을 함께 사용한다.
- 미디어가 없을 때는 전용 대기 프레임을 표시한다.
- 향후 미디어 로딩 실패 시 프레임 크기를 유지하고 대체 문구를 노출한다.
- 실제 비동기 작업이 없으므로 가짜 로딩 상태는 만들지 않는다.

## 접근성

- 의미 있는 제목 단계, 랜드마크, 목록 구조를 사용한다.
- 비활성 상태와 포커스를 색상에만 의존하지 않는다.
- 본문과 배경 명암 대비는 WCAG AA 이상을 목표로 한다.
- 장식용 평가선은 보조기기에서 숨기고, 코칭 단계는 텍스트 목록으로 제공한다.
- 이미지가 추가되면 목적과 평가 방향을 설명하는 대체 텍스트를 작성한다.

## 검증 기준

- 첫 화면에서 이름, 소속, 핵심 약속, 상담 준비 상태가 확인된다.
- 사용자가 제공한 운동 철학 3가지와 차별점 4가지가 누락 없이 반영된다.
- 320px, 360px, 390px, 430px에서 가로 스크롤이 없다.
- 키보드 탐색 시 활성 요소의 포커스가 보인다.
- 모션 축소 설정에서 모든 콘텐츠가 즉시 읽힌다.
- 자바스크립트를 끈 상태에서도 핵심 콘텐츠와 상담 준비 상태가 보인다.
- 브라우저 콘솔 오류가 없고 프로덕션 검증 명령이 성공한다.
- 레퍼런스의 회원 사진, 고유 문구, 가격 또는 확인되지 않은 주장을 포함하지 않는다.

## 향후 확장 계약

### 영상 제공 시

- 히어로 코칭 기준 프레임의 배경을 소유권이 확인된 영상으로 교체한다.
- 데스크톱과 모바일의 별도 크롭·초점 위치를 지정한다.
- 포스터 이미지와 재생 실패 대체 화면을 제공한다.
- 자동 재생 영상은 음소거, 인라인 재생, 사용자 모션 설정 존중을 기본으로 한다.

### 변화 사례 사진 제공 시

- 각 사례에 촬영 시점, 방향, 설명, 공개 허락 및 익명 처리 여부를 확인한다.
- 전후 사진은 같은 비율과 비교 가능한 크롭으로 정규화한다.
- 모바일에서는 가로 스크롤 갤러리 또는 한 사례씩 읽는 스냅 흐름으로 변환한다.
- 결과를 보장하거나 사진만으로 의학적 효능을 주장하지 않는다.

## 완료 정의

- 승인된 디자인 방향을 `DESIGN_BRIEF.md`에 구현 수준으로 매핑한다.
- 정적 페이지를 구현하고 데스크톱·모바일·모션·상태를 검증한다.
- 실제 캡처와 검사 결과를 디자인 브리프의 수용 증거에 기록한다.
- 이후 미디어만 교체해도 전체 구조가 유지된다.
